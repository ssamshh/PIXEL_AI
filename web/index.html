Configuration
Settings are read from the project’s .env file. Restart the server after editing it.
  • PIXEL_MODELHugging Face text model ID.
  • PIXEL_DBSQLite database path.
  • PIXEL_WEB_SEARCH_ENABLEDEnable or disable web search.
  • PIXEL_VISION_API_URLBase URL for an OpenAI-compatible vision API.
  • PIXEL_VISION_MODELVision-capable model name.
  • PIXEL_VISION_API_KEYOptional endpoint key; keep it private.
Voice
Voice input and speech output use browser capabilities and may vary by browser and language.
