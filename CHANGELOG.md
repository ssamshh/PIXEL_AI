# Changelog

## 3.5.0
- Added local and OpenAI-compatible model provider selection.
- Added conversation history endpoint and session rename API.
- Added document question-answering endpoint and UI action.
- Added memory usage count and last-used tracking during retrieval.
- Removed the bundled SQLite database from release artifacts to avoid shipping machine-specific data.
- Updated app branding, configuration guidance, tests, and documentation.

## Carried forward from 3.0
- SQLite memories and sessions, safe calculator, optional web search, document extraction, vision endpoint adapter, browser GUI, browser voice, plugin discovery, FastAPI API, and install scripts.
